# Tres Damas Events — Reel cañero

MP4: `renders/tres-damas-reel-canero.mp4` (1080×1920, 25 s, 30 fps). La versión elegante está en `../tres-damas-reel`.

- **Usuario de Instagram:** variable `instagram` → `npx hyperframes render --variables '{"instagram":"@usuario"}' -o renders/tres-damas-reel-canero.mp4`
- **Música:** variable `musica` o sustituir `assets/audio/musica.mp3`. Si cambias de tema, que vaya a 120 bpm con el *drop* a los 2 s, o los cortes dejarán de ir a tempo.
- **foto-4:** sustituir `assets/foto-4.png`.
- `npm run dev` abre Studio con la línea de tiempo por secciones.
